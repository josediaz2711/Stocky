Supprimer votre compte

Vous pouvez supprimer votre compte Stocky et ses données quand vous le souhaitez. Voici comment :

Depuis l’app

  1. Ouvrez Stocky et connectez-vous avec votre compte.
  2. Touchez « Réglages » dans la barre du bas.
  3. Dans « Vos données », touchez « Supprimer mon compte ».
  4. Si vous voulez garder une copie de vos données, touchez d’abord « Télécharger mes données ».
  5. Dans « Saisissez votre mot de passe pour confirmer », saisissez votre mot de passe. Si vous vous connectez avec Google, saisissez votre e-mail dans « Saisissez votre e-mail pour confirmer ».
  6. Faites glisser « Glissez pour supprimer votre compte ».

La suppression est immédiate (il faut internet). À la fin, vous verrez « Votre compte a été supprimé. »

Si vous n’avez plus l’app

Écrivez-nous à … depuis l’e-mail de votre compte, avec l’objet « Supprimer mon compte ». Si vous écrivez depuis un autre e-mail, nous vous demanderons de confirmer que le compte est à vous. Nous le supprimons dans un délai maximal de 30 jours et vous répondons une fois que c’est fait.

Ce qui est supprimé

  • Votre compte : prénom, nom, e-mail, téléphone, nom de l’entreprise, pays et langue. Vous ne pourrez plus vous connecter avec.
  • Vos données dans le cloud : commandes, articles, clients, acomptes, ventes, frais et mouvements.
  • Vos photos dans le cloud : celles de vos articles, de vos catalogues et votre photo de profil.
  • Le registre de ce que vous avez accepté (Conditions et Confidentialité).
  • Si vous le faites depuis l’app, aussi ce qui concerne ce compte sur ce téléphone.

Ce qui n’est pas supprimé

  • Ce qui est enregistré sur d’autres téléphones où vous vous êtes connecté avec le compte : la session y est fermée, et c’est supprimé en désinstallant Stocky de ce téléphone.
  • Les fichiers que vous avez déjà téléchargés ou partagés (reçus, catalogues, la copie de vos données) : ils sont sur votre téléphone ou chez la personne qui les a reçus.
  • Si vous avez utilisé Stocky en tant qu’invité, sans compte, vos données sont uniquement sur votre téléphone et sont supprimées en désinstallant l’app.
